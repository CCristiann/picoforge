# G1 evidence — CPU graph, 2026-10-13

MacBook Pro M5 Pro, 64 GiB, macOS 27.0.1. Branch `coord/qwen38-g1-cpu`.
Contract and gates: [docs/specs/qwen38/G1.md](../../docs/specs/qwen38/G1.md).

| File | Content |
|---|---|
| `gates.log` | `make test-qwen38-g1`: the 5 sanitized gate tests, every boundary error |
| `real-smoke-run.log` | `/usr/bin/time -l` of the 48-layer run on the real Q2 checkpoint |
| `real-smoke.json` | top-5 logits per position, rank of the prompt's next token, per-layer RMS |

The synthetic fixture is regenerated by `make build/qwen38-g1/graph.gguf`
(seed 3811); the oracle needs `make qwen38-test-assets` once.

The real run is a **smoke test**: it shows that all 48 layers bind to the
real catalog and produce finite logits. It is not a parity measurement (no
oracle on real weights at graph level yet; G3 compares against DwarfStar).
Wall time is dominated by first-touch page faults on the mapped checkpoint
(173 s user of 371 s wall); single-threaded scalar CPU, no optimization, no
thermal logging: do not read it as a performance number.
