# Chat locale

Palette coerente con il report: carta fredda #f4f7fa, inchiostro #173048,
blu #3157ce, verde stato #12695e, linea #d8e1e9, bianco #ffffff.
Avenir Next per testo e comandi; monospace soltanto per codice e token numerici.

Layout: una colonna di conversazione larga al massimo 760 px, allineata a
sinistra, compositore in basso e stato del motore sempre visibile in alto.

```
picoforge / Chat locale             stato    Nuova conversazione

  invito iniziale / messaggi nella loro sequenza

  [messaggio                                                 ]
  limite risposta         metriche reali      Interrompi  Invia
```

La conversazione è il centro, senza dashboard di schede o numeri simulati.
Le metriche compaiono solo quando il motore le invia. Un solo accento blu nei
controlli. Il report usa lo stesso linguaggio visivo; nessun font remoto.
Revisione: tolti sidebar e titolo promozionale, che non servono alla chat.
