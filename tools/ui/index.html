Decode reads every one of the model’s 596 M weights to produce a single token. That is 1.19 GB in bf16, so no implementation can exceed 307 ÷ 1.19 = 258 tokens per second on this machine. The percentage above is the only honest score.

Orange marks whitespace made visible. Red marks a token that is not valid UTF-8 on its own — a fragment of a multi-byte character. Byte-level BPE merges bytes, not characters, so an emoji is routinely split across two or three tokens. Nothing is untokenisable because all 256 single bytes are themselves tokens.
